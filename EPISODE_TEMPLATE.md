## Narration Script

Target 2,000–3,000 words.

Use spoken language.

Use short paragraphs.

Avoid screenplay formatting unless dialogue is needed.

## Scene Plan

For each scene:

- Scene number
- Narration start line
- Duration
- Shot type
- Characters
- Action
- Location
- Time of day
- Mood
- Image prompt
- Camera movement
- Sound effect
- Music cue
- Continuity notes

## Image Prompt Rules

Every prompt should specify:

- Exact character appearance
- Island and year
- Historically plausible clothing
- Environment
- Emotion
- Camera angle
- Lighting
- Cinematic realism
- 16:9
- No text
- No modern objects

## Thumbnail

- One main face or confrontation
- Strong emotion
- Simple composition
- Optional 2–4 words
- High contrast between subject and background
- No crowded battle scene
